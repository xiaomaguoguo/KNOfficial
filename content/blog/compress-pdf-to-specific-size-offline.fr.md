# Comment compresser un PDF à une taille spécifique (ex: 200Ko, 1Mo) localement

Nous avons tous vécu le **cauchemar de l'\"Échec du téléchargement\"**.

Vous essayez de soumettre une candidature ou un formulaire. Vous cliquez sur envoyer, et le portail crie : **"Fichier trop volumineux. Taille maximale : 2Mo."**
Vous vérifiez votre fichier. Il fait 2,1Mo. Vous voulez juste enlever ces 0,1Mo.

Vous essayez les compresseurs en ligne standard. Soit :
1.  Ils le compressent à **1,5Mo** (détruisant la qualité).
2.  Ils le compressent à **2,05Mo** (toujours trop gros).
3.  Ils vous demandent de payer.

## Note Technique : En Coulisses

Pour obtenir une telle compression (ex: réduire un scan de 10Mo à 500Ko), nous utilisons une technique appelée **"Re-distillation"**.
Nous convertissons chaque page de votre PDF en une image optimisée, puis les empaquetons à nouveau dans un nouveau PDF.

> [!WARNING]
> **Compromis** : Comme les pages sont converties en images, le texte dans le PDF compressé **ne sera plus sélectionnable**. Parfait pour les scans et reçus, moins pour les contrats.

## Guide Étape par Étape

1.  Glissez votre fichier dans le **[Compresseur PDF](/pdf-compress)**.
2.  **L'étape magique** : Cherchez la case "Taille de fichier cible". Entrez votre limite (ex: `2.0` pour 2Mo, ou `0.2` pour 200Ko).
3.  Cliquez sur **Compresser PDF**.
4.  Téléchargez votre nouveau PDF léger.
