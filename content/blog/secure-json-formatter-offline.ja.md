# ランダムなJSONフォーマッタに機密データを貼り付けるのはやめましょう

## あなたが見過ごしているかもしれないセキュリティの悪夢

想像してみてください。午前2時、APIレスポンスのデバッグをしています。JSONはインデントがなく、すべてが1行にまとまっていて読みにくい状態です。あなたはペイロード全体（ユーザーのメールアドレス、APIトークン、セッションIDを含む）をコピーし、Googleで見つけた最初の「JSONフォーマッタ」に貼り付けます。

**不都合な真実**：あなたは今、会社の機密データを、何も知らないランダムなサーバーに送信してしまいました。

- そのサーバーは誰が所有していますか？
- 彼らはあなたのデータをログに記録していますか？
- データは第三者に販売されていませんか？
- データ侵害で流出する可能性はありませんか？

あなたには分かりません。そして、それは恐ろしいことです。

## 解決策：100%クライアントサイドのJSON処理

**KNothingのJSONフォーマッタ**は、この問題を完全に解決します。その方法は以下の通りです：

### ゼロ・サーバー通信

私たちのJSONフォーマッタは**完全にブラウザ内**で動作します。JSONを貼り付けると：

1. データはブラウザのメモリ内に留まります
2. ネイティブのJavaScript（`JSON.parse()` と `JSON.stringify()`）を使用します
3. **ネットワークリクエストはゼロ**です
4. データがサーバーに触れることはありません

信じられませんか？ブラウザのデベロッパーツール（F12）を開き、「ネットワーク」タブを確認してください。JSONを整形する際、**リクエストがゼロ**であることが分かります。

### オフライン対応 (PWA)

すべてがクライアントサイドで実行されるため、以下のことが可能です：

1. ページを一度ロードする
2. **インターネットを切断する**
3. JSONの整形を続ける

試してみてください。Wi-Fiをオフにしても、PWA（Progressive Web Apps）技術のおかげで完璧に動作します。

## 技術解説：仕組み

技術に興味がある方のために、裏側で何が起きているか説明します：

```javascript
// 1. JSONを解析（構文検証）
const parsed = JSON.parse(yourJsonString)

// 2. 2スペースのインデントで整形
const beautified = JSON.stringify(parsed, null, 2)

// 3. 圧縮（すべての空白を削除）
const minified = JSON.stringify(parsed)
```

これらすべてが**ブラウザのJavaScriptエンジン**内で発生します。サーバーも、データベースも、ログもありません。

## 実際に役立つ機能

### 🔍 即時検証

形式が正しくないJSONを貼り付けると、**即座にフィードバック**が得られます：

- 構文エラーのハイライト
- デバッグ用の行番号
- 明確なエラーメッセージ（難解なサーバーエラーではありません）

私たちが検出する一般的な問題：
- 末尾のカンマ（JSONでは無効）
- 引用符で囲まれていないキー
- 二重引用符の代わりに単一引用符の使用
- 括弧や中括弧の欠落

### 📦 本番環境用の圧縮

APIペイロードや設定ファイル用にJSONを圧縮する必要がありますか？

- すべての空白を削除
- ファイルサイズを約40〜60%削減
- 本番環境に最適

### ✨ 人間向けの整形（Beautify）

JSONを読みやすくします：

- 2スペースのインデント（業界標準）
- 適切な改行
- カラーシンタックスハイライト
- ワンクリックでコピー

### 🚀 ファイルサイズ制限なし

1MBや5MBに制限されている多くのオンラインツールとは異なり、私たちのフォーマッタは**ブラウザのRAM**によってのみ制限されます。以下でテスト済みです：

- 50MB以上のJSONファイル
- 深くネストされたオブジェクト（100階層以上）
- 100,000以上のアイテムを含む配列

## よくある質問 (FAQ)

### Q: 本当に安全ですか？

**A:** はい。ブラウザのデベロッパーツール（F12）→「ネットワーク」タブを開いてください。JSONを貼り付けて整形します。**ネットワークリクエストがゼロ**であることが確認できます。コードも公開されており、右クリック→「ページのソースを表示」で確認できます。

### Q: 大きなファイルを扱えますか？

**A:** はい。100MBまでのファイルでテストしています。唯一の制限は、ブラウザの利用可能なRAMです。目安：
- 小さいファイル (<1MB): 瞬時
- 中程度のファイル (1-10MB): 1〜2秒
- 大きいファイル (10-50MB): 3〜5秒

### Q: モバイルでも使えますか？

**A:** モバイルブラウザ（Chrome, Safari, Firefox）で完璧に動作します。PWAはホーム画面にインストールしてオフラインでアクセスすることも可能です。

### Q: 整形されたJSONを共有したい場合は？

**A:** 「コピー」ボタンを使用して整形された出力をコピーし、好みの方法（メール、Slackなど）で共有してください。私たちはデータを保存または送信しません。

## プライバシーの約束

私たちは3つの約束をします：

1. **追跡なし**：Google Analyticsなし、Cookieなし、フィンガープリントなし
2. **保存なし**：JSONは保存されません（localStorageにも保存されません）
3. **ネットワークなし**：サーバーリクエストゼロ（デベロッパーツールで確認してください）

あなたのデータは**あなたのもの**です。それだけです。
