# JWT 토큰을 온라인에 붙여넣지 마세요 (위험합니다)

## 단순히 디코딩하는 것이 아니라 데이터를 유출할 수 있습니다

우리는 모두 그런 적이 있습니다. 인증 문제를 디버깅하고 있고 JWT의 내용을 확인해야 합니다. "jwt decoder"를 검색하고 첫 번째 결과를 클릭한 다음 프로덕션 토큰을 붙여넣습니다.

**멈추세요.**

방금 민감한 사용자 데이터, 세션 키 또는 심지어 관리자 자격 증명을 알 수 없는 타사 서버로 전송했을 수 있습니다.

- 그 웹사이트는 누가 운영합니까?
- 그들이 당신의 토큰을 기록하고 있습니까?
- 당신의 데이터가 판매되거나 악의적인 목적으로 사용됩니까?

가장 인기 있는 도구조차도 해킹되거나 인수되면 악의적으로 변할 수 있습니다. 위험이 너무 큽니다.

## 정확히 무엇이 문제입니까?

JWT(JSON Web Token)에는 종종 다음이 포함됩니다.
- **사용자 ID 및 이메일**: 사용자를 식별하는 데 사용됩니다.
- **역할 및 권한**: 예: `admin:true` 또는 `scope:read_write`.
- **세션 및 만료**: 토큰이 만료되었더라도 유효한 기록 데이터가 포함되어 있습니다.

이것을 온라인 디코더에 붙여넣으면 **네트워크를 통해 자격 증명을 전송**하는 것입니다. 이는 **최소 권한** 및 **데이터 기밀성**이라는 기본 보안 원칙을 위반합니다.

## 더 나은 방법: 로컬 오프라인 디버깅

**KNothing JWT 디버거**는 이 문제를 해결하도록 설계되었습니다. 이것은 **서버에 데이터를 보내지 않고** JWT를 디코딩하고 디버깅하는 순수 클라이언트 측 도구입니다.

### 왜 KNothing JWT 디버거를 선택해야 합니까?

1.  **100% 클라이언트 측 실행**: 토큰은 브라우저를 떠나지 않습니다. 인터넷 연결을 끊어도 완벽하게 작동합니다.
2.  **즉시 디코딩**: 서버 응답을 기다릴 필요가 없습니다. 토큰을 붙여넣고 디코딩된 헤더와 페이로드를 즉시 확인하세요.
3.  **사람이 읽을 수 있는 시간 표시**: Unix 타임스탬프를 변환하느라 고생할 필요가 없습니다. `iat`(발급 시간) 및 `exp`(만료 시간)를 읽기 쉬운 날짜 형식으로 자동 변환합니다.
4.  **아름다운 JSON 형식**: JSON 구조를 자동으로 형식화하여 읽고 디버깅하기 쉽게 만듭니다.
5.  **보안 우선**: 추적기, 분석 도구 또는 외부 스크립트를 사용하지 않습니다. 귀하의 개인 정보 보호가 최우선입니다.

## 안전하게 JWT를 디버깅하는 방법

KNothing JWT 디버거를 사용하는 것은 매우 간단합니다.

1.  [knothing.com/jwt](/jwt)를 방문하세요.
2.  입력 상자에 JWT를 붙여넣으세요.
3.  디코딩된 헤더와 페이로드를 즉시 확인하세요.
4.  만료 상태와 타임스탬프를 확인하세요.

그게 다입니다. 복잡한 설정도, 위험도 없습니다.

## 기술 세부 정보: PWA입니다

우리의 JWT 디버거는 **Progressive Web App(PWA)**입니다. 즉:
- 데스크톱이나 모바일 장치에 설치할 수 있습니다.
- 완전히 오프라인에서 작동합니다.
- 네이티브 앱처럼 매우 빠르게 로드됩니다.
