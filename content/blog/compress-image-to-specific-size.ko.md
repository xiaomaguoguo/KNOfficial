# 업로드 없이 이미지를 특정 크기로 압축하는 방법

## 문제점

프로필 사진이나 문서를 업로드하려고 할 때 "파일 크기가 너무 큽니다"라는 메시지를 받은 적이 있습니까? 정말 답답합니다.
대부분의 온라인 이미지 압축기에는 두 가지 결함이 있습니다:
1.  **목표 크기 제어 불가**: "이걸 정확히 50KB로 만들어줘"라고 말할 수 없습니다.
2.  **개인정보 위험**: 개인 사진을 서버에 업로드해야 합니다.

## 해결책: KNothing 스마트 이미지 압축기

이 문제를 해결하기 위해 **[스마트 이미지 압축기](/compress)**를 만들었습니다.

### 클라이언트 측 정밀도

이미지를 클라우드로 보내는 대신 브라우저의 성능을 사용하여 **기기에서 직접** 이미지를 압축합니다.

이것은 다음을 의미합니다:
*   **업로드 제로**: 사진이 컴퓨터나 휴대폰을 떠나지 않습니다.
*   **정밀 제어**: 필요한 정확한 파일 크기 제한을 설정합니다.

## 이미지를 특정 크기로 압축하는 방법

1.  **[이미지 압축기](/compress)**로 이동합니다.
2.  이미지를 **드래그 앤 드롭**합니다.
3.  **마법의 단계**: **"최대 파일 크기 (MB)"** 슬라이더 또는 입력을 찾습니다.
    *   **200KB**가 필요합니까? `0.2`를 입력하세요.
    *   **50KB**가 필요합니까? `0.05`를 입력하세요.
4.  도구가 해당 크기에 맞는 최적의 품질을 자동으로 계산합니다.
5.  **내보내기 및 압축**을 클릭합니다.

## 자주 묻는 질문(FAQ)

### 이미지를 정확히 50KB로 압축할 수 있습니까?
네! 설정에 `0.05` MB만 입력하면 됩니다. 압축기는 품질과 크기를 조정하여 목표를 달성하려고 시도합니다.
