# Cara Kompres PDF ke Ukuran Tertentu (misal 200KB, 1MB) Secara Lokal

Kita semua pernah menghadapi **Mimpi Buruk "Gagal Mengunggah"**.

Anda mencoba mengirimkan lamaran pekerjaan atau formulir visa. Anda menekan unggah, dan portal berteriak: **"File terlalu besar. Ukuran maksimum: 2MB."**
Anda memeriksa file Anda. Ukurannya 2.1MB. Idealnya, Anda hanya ingin membuang 0.1MB itu.

Anda mencoba kompresor online standar. Mereka antara:
1.  Mengompresnya menjadi **1.5MB** (menghancurkan kualitas).
2.  Mengompresnya menjadi **2.05MB** (masih terlalu besar).
3.  Meminta Anda membayar untuk kompresi "Pro".

## Catatan Teknis: Bagaimana Kami Melakukannya

Untuk mencapai kompresi ekstrem seperti itu (misal mengecilkan scan 10MB menjadi 500KB), kami menggunakan teknik yang disebut **"Penyulingan Ulang" (Re-distilling)**.
Alih-alih hanya menghapus metadata, kami mengubah setiap halaman PDF Anda menjadi gambar yang sangat dioptimalkan dan kemudian mengemasnya kembali menjadi PDF baru.

> [!WARNING]
> **Kompromi**: Karena halaman diubah menjadi gambar, teks dalam PDF yang dikompresi **tidak akan dapat dipilih atau disalin lagi**. Ini sempurna untuk pindaian dan tanda terima, tetapi mungkin tidak untuk kontrak di mana Anda perlu menyalin-tempel teks nanti.

## Panduan Langkah-demi-Langkah

1.  Seret dan lepas file Anda ke **[Kompresor PDF](/pdf-compress)**.
2.  **Langkah Ajaib**: Cari kotak "Ukuran File Target". Masukkan batas Anda (misal `2.0` untuk 2MB, atau `0.2` untuk 200KB).
3.  Klik **Kompres PDF**.
4.  Download PDF baru Anda yang ringan.

## Pertanyaan yang Sering Diajukan (FAQ)

### Bisakah saya mengompres PDF 100MB menjadi 1MB?
Secara teknis, ya. Namun, kualitas gambar akan sangat rendah. Kami menyarankan target yang masuk akal.

### Apakah data saya aman?
Tentu saja. Alat ini berjalan sepenuhnya di browser Anda. File Anda tidak pernah meninggalkan komputer Anda. Anda bahkan dapat **mematikan Wi-Fi** sebelum menambahkan file!
