# 停止在网上粘贴 JWT 令牌（这样做很危险）

## 您不仅仅是在解码，您可能在泄露数据

我们都做过。您正在调试身份验证问题，需要检查 JWT 的内容。于是您搜索“jwt decoder”，点击第一个结果，然后粘贴您的生产环境令牌。

**停下。**

您刚刚可能将敏感的用户数据、会话密钥甚至管理员凭据发送给了未知的第三方服务器。

- 谁在运行那个网站？
- 他们在记录您的令牌吗？
- 您的数据会被出售或用于恶意目的吗？

即使是最受欢迎的工具也可能因为被黑客攻击或被收购而变得恶意。风险实在太高了。

## 这种做法到底有什么问题？

JWT（JSON Web Tokens）通常包含：
- **用户 ID 和电子邮件**：用于识别用户。
- **角色和权限**：例如 `admin:true` 或 `scope:read_write`。
- **会话及过期时间**：即使令牌已过期，它仍然包含有效的历史数据。

当您在在线解码器中粘贴这些内容时，您是在通过**网络发送凭据**。这违反了基本的安全原则：**最小特权**和**数据保密性**。

5.  **安全第一**：我们不使用任何跟踪器、分析工具或外部脚本。您的隐私是我们的首要任务。
